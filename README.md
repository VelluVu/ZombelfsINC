# ZombeIsINC

> A 3D top-down zombie shooter built in Unity as a school project.

![Unity](https://img.shields.io/badge/Engine-Unity-black?logo=unity) ![Language](https://img.shields.io/badge/Language-C%23-purple) ![Type](https://img.shields.io/badge/Type-School%20Project-orange)

## About

**ZombeIsINC** is a 3D top-down shooter set against a zombie survival theme. Built in Unity as a school project, it focuses on wave-based enemy spawning, shooting mechanics, and basic survival gameplay — a classic game programming exercise for learning combat systems and enemy AI.

## Features

- 🧟 Wave-based zombie enemy spawning
- 🔫 Top-down shooting mechanics
- 🎯 Aiming and projectile system
- 🧠 Enemy AI — chase and attack behaviour
- ❤️ Player health and damage system
- 🌊 Increasing difficulty per wave
- 🗺️ Arena-style level design

## Built With

- **Unity** (3D)
- **C#** — gameplay, AI, and combat scripting

## Getting Started

### Prerequisites

- Unity Editor (2019.x or later recommended)

### Running the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/VelluVu/ZombeIsINC.git
   ```
2. Open in Unity Hub and load the project folder.
3. Open the main scene and press **Play**.

## Context

A school project that introduced wave management, combat feedback systems, and enemy AI in a 3D environment — skills that fed directly into later ARPG and tower defense projects.
